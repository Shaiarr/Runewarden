# Runewarden 0.9.4

This development update makes native minigame guides explicitly opened, current-state guidance. Open current guide starts at the supported current objective, follows native changes while open and closes on exit or completion.

## Behavior

- Native minigame guides open only through an explicit player action. The controller accepts profile-bound current-objective observations, confirmed completed steps and explicit terminal observations. Opening reconciles existing observations immediately; later native changes advance the selected objective while the guide stays open.
- Already completed work is recognized from supported native activity facts, not from a saved checklist position alone. Unknown observations do not fabricate completion.
- Native cycle progress is transient and separate from saved manual checklists. A previously completed manual guide does not hide the current active cycle. Sidebar and HUD present the same current native task.
- Native minigame exit, a final confirmed step or Close guide dismisses the selected guide. Close guide is available in the sidebar, guide HUD and overlay menu. Selection/account guards prevent stale queued updates or activity detection from reopening it; another explicit open is required. The guide's owned HUD, markers, bank focus and route clear on dismissal; manually replaced routes remain the player's. Closing a guide does not finish the tracked activity run or turn an exit into a recorded win.
- Guide dismissal releases its bank query and requirements without waiting for a future game tick. An independently selected loadout or supply filter retains its own focus.
- Minigame, active farm-run and attributed training observations share this flow. Source-specific completion conditions remain distinct: a current objective, completed phase and completed activity are separate facts.
- Open-ended training has no synthetic final step. Explicit run targets or supported finite activity completion can provide terminal evidence; otherwise the remaining completion stays manual. Subjective boss/wave lessons retain manual completion and the existing supported arena/death dismissal. Quest walkthroughs remain in the external Quest Helper.

Foundry's native mould state resets after preform pickup, so carried/equipped and stored preform facts take precedence over that reset. Confirmed predecessor steps apply to the observed sword cycle; they do not complete mould-purchase or multi-sword learning milestones. Account/activity reset discards pending completion proof. The minigame exit tracker matches the previously witnessed activity. Instance change, departure from its witnessed/source region and plane, or a different positively detected activity can establish exit; supported internal MTA, Volcanic Mine and BA areas are retained. A bank visit or temporary missing HUD does not close the guide. This is not a certified boundary for every doorway within the same non-instanced region.
