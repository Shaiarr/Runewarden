# Gathering and harvest countdowns

Node countdowns use the existing scene overlay above the selected resource. Choose **Text**, **Radial** or **Both** in the Skilling panel or RuneLite's Node countdown style setting. Both is the default. Observed respawns use gold rings; supported tree lifetimes use white dashed rings and retain the estimate marker.

The lifetime estimate begins at the first correlated log XP for the selected tree. Its expiry means the next successful log may deplete the tree, not that the tree has certainly disappeared. When that window expires, the ring gives way to “Next log may deplete”. Ordinary rocks, randomly depleting trees, planted trees and species without verified lifetime rules retain “Until depleted”; they do not receive a fabricated lifetime ring. Native respawn events continue to use their supplied tick durations and world-view location, including Motherlode level checks.

The Harvest HUD has its own independent Text/Radial/Both setting in the Timers panel and RuneLite settings. Both adds a ring beside the existing countdown; Radial puts a compact rounded-up duration inside the ring. Due crops keep their estimated check reminder, and an observed completed bird house remains an observed completion. Changing presentation never changes timer selection or farming state.

Native Time Tracking's public summaries expose group deadlines rather than planting timestamps. A harvest ring therefore represents the **remaining window from first observation of that deadline**, not the percentage of a crop's entire growth cycle. Its start stays stable across refreshes and resets only when that group's deadline changes or its observation/account is cleared. The Timers control has a tooltip explaining this distinction. No full crop duration is guessed, and no native private fields or configuration are read.

Rendering uses immutable node snapshots published on observed events/game ticks. Harvest selection/order is cached per second, native reading and selection revision; sorting and native tracker work are not repeated each frame. Scene changes, logout, death and profile switches retain the existing clearing rules. Unobserved/empty groups do not acquire countdowns, and cached rows cannot expose another character's timers.

Headless tests cover all three scene/HUD modes, supported versus unknown durations, lifetime expiry, observed-window stability and resets, selection-cache invalidation and account transitions. QA images are generated under `build/reports/gathering-radial-modes.png` and `build/reports/harvest-radial-modes.png`. In-game positioning and readability still need the release acceptance pass.
