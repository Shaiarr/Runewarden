# Slayer assignment

The **Slayer** sidebar reads the current assignment directly from the pinned RuneLite 1.13.2 public game variables and Slayer DB tables. It shows the live remaining count, original assignment size (including current count modifiers), completed portion, Slayer points and the appropriate normal, Wilderness or Mortimer streak. It works with the native Slayer plugin disabled and does not enable or modify another plugin.

The sidebar separates **Assignment** and **Task planning**. The 0.7 planner now supports master selection with account-aware filters, exact creature/setup plans, personally measured XP/profit comparisons, bounded assignment odds, skip/block/point simulation and shared activity start/observation context. The editor separates decisions, preparation and rates into three pages. Full behavior, native checks, mathematical assumptions and supported limits are documented in [slayer-planning.md](slayer-planning.md).

Assignment name, boss sublist and assigned area use the same public DB table strategy as RuneLite's native Slayer adapter. Name and location lookups run on the client thread and are cached until assignment identity changes; monster references are built once for that assignment. The remaining counter and equipment checks update from observed state. Missing DB rows show unavailable assignment data instead of reusing a previous name. Logging out, changing profile or clearing the assignment removes old task details. The UI receives immutable snapshots and does not access the client from Swing callbacks.

The bundled RuneLite task-name map contains **152 task families**, including native alternative monster names such as Cerberus for Hellhounds and Brutus for Cows. A creature selector links that context to the local monster catalogue's documented attack styles, static usual protection, elemental vulnerability, defence bonuses and attributes. Ordinary task creatures appear before boss alternatives when matched. These are **reference alternatives**, not confirmation that a selected variant is valid in a location-restricted assignment. The actual assigned area remains visible, with an explicit Wiki location link.

The narrow sidebar uses full-width assignment and creature cards with left-aligned content. The default creature view shows attacks, elemental weakness and usual protection. **More combat details** expands defence bonuses, attributes and provenance; it starts collapsed. **Task Wiki**, **Location Wiki** and **Creature Wiki** have short, complete button labels. Their destinations and task data are unchanged. Layout checks use RuneLite's actual look and feel at 206 pixels of module width.

Selected creatures link to matching bundled boss guides; opening one uses the ordinary guide selection and its shared supplies, bank filtering and progression. Task-equipment cards link to the shared item browser. All external Wiki navigation requires an explicit button click. No combat action, prayer input, task cancellation or remote lookup is performed automatically.

Nine revision-sourced equipment rules cover nose protection, banshee screams, dust/smoke masks, basilisk/cockatrice shields, Killerwatt boots, Fever spider gloves, Wall beast head protection, Gargoyle finishing items and Rockslug finishing items. Checks distinguish equipped items from items merely carried and recognise worn Slayer helmet recolours by their real item definition. Conditional alternatives are stated on the relevant card. These rules are a supported subset; an empty equipment list does not assert that a task has no other requirements. Source revisions and separate licences accompany `slayer-task-reference.json`.
