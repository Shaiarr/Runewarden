# Command dashboard and harvest reminders

The Runewarden command dashboard is one movable RuneLite overlay. Hold Alt and drag its border to move the whole block. The clock, world, scoped normal-attack max hit and worn equipment move together. The dashboard and clock each have a display toggle; UTC can replace the operating system's local 24-hour clock. It does not move or intercept the game minimap or resource orbs.

Equipment comes from the logged-in player's current `InventoryID.WORN` container. RuneLite's `EquipmentInventorySlot` defines 14 raw indices: the dashboard draws the 11 real item slots in the native worn-equipment arrangement and skips the appearance-only arms, hair and jaw indices. Sprites and quantity labels come from `ItemManager.getImage(id, quantity, stackable)`. No bank snapshot or inventory is substituted for missing equipment. Logout and profile changes clear the equipment and combat reading.

World number and world classification come from `Client.getWorld()` and `Client.getWorldType()`. A skill-total world is labelled as such; the dashboard does not guess a particular skill-total requirement when it has not received one.

Maximum-hit labels distinguish `BASE MELEE`, `BASE RANGED`, `BASE MAGIC`, explicit spell/dart inputs and the Tbow target reference. The Tbow reference uses the exact target variant's published Magic level, excluding live drains and raid scaling. Scythe shows its first-hit scope separately. Unsupported formulas, unknown selected spells, concealed dart supplies and unimplemented effects show a dash and reason; no previous equipment value is retained. See `current-max-hit.md` for formulas, input conditions and primary sources.

The separate harvest HUD lists selected harvest categories and their estimated completion times. Its context menu opens Harvest Control. The panel reads the active built-in Time Tracking plugin's public `FarmingTracker` and `BirdHouseTracker` services. If Time Tracking is paused, the panel directs the player to enable it in RuneLite's own plugin settings. Runewarden does not start or configure the native plugin, replace its observations or write guessed crop timers.

The Timers sidebar now lets each RuneScape profile choose its tracked categories. With no saved choices, only observed, nonempty categories are selected. Explicit choices—including switching every timer off—persist for that profile. The command-centre sidebar and harvest HUD list every selected observed category by name with its own due state or countdown; unknown and empty categories never produce due alerts. Clicking a command-centre harvest row opens Farm runs, preselecting a matching route where available. Special crops and categories without a bundled route open the picker.

Stable tracking keys are `bird-house`, `herb`, `tree`, `fruit-tree`, `special`, `flower`, `allotment`, `bush`, `grape` and `hops`. These are native Time Tracking groups. Hardwood and redwood patches share the Tree group; calquat, celastrus and crystal trees share the Fruit tree group; seaweed and Hespori share Special. They are not independent per-crop timers. Selection writes use the captured profile key and session generation; delayed actions from an old account are ignored.

Harvest counts refer to Time Tracking groups, not individual patches. An estimated crop deadline is a reminder to inspect its patches; it does not guarantee healthy, harvestable crops. Unknown and empty groups stay distinct. These estimates follow Time Tracking's own soonest/all-patches preference. Native Time Tracking continues to own notifications and tracking observations.

Implementation references are the official pinned RuneLite 1.13.2 API/client source JARs: `EquipmentInventorySlot.java`, gameval `InventoryID.java`, `WorldType.java`, `ItemManager.java`, `TimeTrackingPlugin.java`, `FarmingTracker.java`, and `BirdHouseTracker.java`. Ordinary current maximum hit is not exposed as a server varbit or varp in this pinned API; it must be calculated for an explicit supported attack scope. Observed hitsplats are never presented as theoretical maximum damage.
