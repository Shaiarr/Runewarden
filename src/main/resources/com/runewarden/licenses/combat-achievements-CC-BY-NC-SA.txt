Adaptation: converted factual task metadata to a local JSON index; preserved task-specific preparation/restrictions and Strategy/Method paragraphs as plain text with Wiki presentation templates, images, citations, link markup and navigation removed. Source revision URLs preserve access to the original context and contributors/history. Typed skill and quest requirements were extracted only from explicit introductory requirement wording. Referenced item links were matched to the bundled item-name snapshot, using a representative item ID for browser navigation; they are not asserted to be mandatory equipment. Linked boss guides and suggested task ordering are Runewarden additions.

655 native task IDs and all six difficulties are represented. Numeric points are 1–6 per task according to difficulty. Regular-account reward targets retain their declared scope; Group Ironman adjustments are not inferred.
