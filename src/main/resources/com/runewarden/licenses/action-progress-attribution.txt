Runewarden is distributed without charge. Timing facts were selected, normalised
and implemented as local observation rules. The UI and implementation are original;
this file identifies the factual sources, their revisions and the changes made.
No prose walkthrough or combat attack-speed table is reproduced.

Native animation identifiers/durations use RuneLite 1.13.2 public APIs and the
already attributed RuneLite API dependency. Existing banked recipe provenance is
retained in banked-xp-recipes.json.
