RuneLite 1.13.2 HUD facts and native calculation references

Source revision: runelite-parent-1.13.2
https://github.com/runelite/runelite/tree/runelite-parent-1.13.2/runelite-client/src/main/java

The retained action-recipes.json item transformations use the named skill action
enums recorded per entry. Resource hovers also read the native gathering/cooking
enums. Farming clock alignment and birdhouse observations reference the native
trackers. Effect durations and consumable projections use the native public
TimersAndBuffs and ItemStatChanges definitions. Native implementations consumed
from RuneLite remain unchanged dependencies, not copied runtime classes.
Full original source notices follow, grouped only when their text is identical.
