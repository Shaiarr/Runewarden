Harvest destinations and POH routing facts

FarmPatchDestinations uses RuneLite 1.13.2 FarmingPatchLocation map-marker
coordinates; its source header is preserved in that Java file and below.
Source: https://github.com/runelite/runelite/blob/runelite-parent-1.13.2/runelite-client/src/main/java/net/runelite/client/plugins/worldmap/FarmingPatchLocation.java

poh-travel-portals.json records Shortest Path 1.21.3 portal names, object IDs and
transport-item identifiers with exact file SHA256 pins. The virtual owned-house
landing follows the same native Shortest Path model. No pathfinder implementation
is copied into Runewarden; an installed and enabled companion handles routes.
Source: https://github.com/Skretzo/shortest-path/tree/37abff3a3345185fc11fccecae04d8170de25a11
