Runewarden original reward sound set

white-chime.wav, green-chime.wav, blue-chime.wav, purple-sting.wav,
gold-fanfare.wav and quiet-tick.wav are original synthesized sounds created
for this project. They contain no sampled OSRS/Jagex audio, third-party
recordings or copied game melodies.

These six audio assets and their synthesis arrangements are dedicated to
the public domain under CC0 1.0 Universal:
https://creativecommons.org/publicdomain/zero/1.0/

The deterministic generator is tools/generate-reward-sounds.py.
The generator program and plugin Java code retain their BSD-2-Clause license.
