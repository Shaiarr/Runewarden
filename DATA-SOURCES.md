# HUD data sources

Runewarden HUD 0.10.6 contains six account-independent JSON reference resources. It reads supported live observations through RuneLite's public APIs. The original Java/UI implementation is BSD-2-Clause; third-party source and data keep their own notices and terms. See [NOTICE](NOTICE) and [`src/main/resources/com/runewarden/licenses/`](src/main/resources/com/runewarden/licenses/).

| Retained material | Primary source | Attribution and scope |
| --- | --- | --- |
| `action-recipes.json` | RuneLite 1.13.2 skill-calculator action enums; individually identified Wiki potion facts | Exact item transformations, levels and XP for action detection and hovers. Native BSD notices are in `runelite-hud-reference-BSD-2-Clause.txt`; Wiki portions retain `wiki-reference-CC-BY-NC-SA.txt`. This is not a banked-XP planner. |
| `skilling-resource-details.json` | Per-entry OSRS Wiki pages/revisions and native RuneLite gathering/cooking facts | Resource uses and farming-stage/payment facts. Wiki-derived portions retain CC BY-NC-SA 3.0 attribution; native definitions retain BSD notices. |
| `farming-native-snapshot.json` | RuneLite 1.13.2 `FarmingWorld`, `PatchImplementation` and `Produce` | Native patch/crop/state facts, covered by `runelite-farming-data-BSD-2-Clause.txt`. Observed timer estimates are separate from these static references. |
| `poh-travel-portals.json` | [Shortest Path 1.21.3 at 37abff3a](https://github.com/Skretzo/shortest-path/tree/37abff3a3345185fc11fccecae04d8170de25a11) | Portal names/object IDs and relevant transport-item IDs. Exact source file SHA256 pins remain in the JSON; full BSD terms remain in `harvest-travel-BSD-2-Clause.txt`. The companion pathfinder is not embedded in the Hub plugin. |
| `slayer-native-tasks.json` | RuneLite 1.13.2 `Task`; selected pinned Wiki equipment pages | 152 native task names, NPC aliases and icon identities, plus selected equipment notes. Native BSD and separate Wiki notices remain in `runelite-slayer-BSD-2-Clause.txt` and `slayer-equipment-CC-BY-NC-SA.txt`. No private native API is accessed. |
| `slayer-task-locations.json` | Individual Wiki task/monster pages and the pinned earlier reference snapshot | 26 named location examples across 21 task names/aliases, with per-entry source URLs and a checked date. These examples do not establish permission for a restricted assignment and are not an exhaustive spawn catalogue. |

Retained source-level facts also have explicit notices:

- Farm destinations use RuneLite 1.13.2 `FarmingPatchLocation` map markers. `FarmPatchDestinations.java` preserves its full source header; the binary notice is repeated in `harvest-travel-BSD-2-Clause.txt`.
- Farming clock alignment, native birdhouse observations, compost correlation, gathering-node timing, effect durations, consumable projections and daily claims retain the applicable native BSD notices. These records do not imply every crop, resource or activity is supported.
- Individual birdhouse cards read native Time Tracking's character-bound `birdhouse.<varp>` records without modifying them. The observed state and timestamp must match the current native varp; missing or mismatched records do not create timers. Four native house positions, state/item mappings and the 50-minute duration come from RuneLite 1.13.2 `BirdHouseSpace`, `BirdHouseState`, `BirdHouse`, `BirdHouseTracker` and `BirdHouseTabPanel`; their BSD notices are preserved in `runelite-hud-reference-BSD-2-Clause.txt`.
- Mixed farming tabs are split by the native snapshot's patch implementation. Ordinary tree and fruit-tree summaries exclude hardwood, spirit, redwood, calquat, celastrus and crystal trees. Hespori and other special patches have individual reminder categories. These read native character-bound `<region>.<varbit>` records and call the public native `FarmingTracker.getTickTime` for account offsets; they never compare a remote patch against a reused live varbit. Native earliest/latest completion preferences and summary semantics are retained. `FarmHarvestTimers.java` preserves the native tracker's BSD notice.
- Varlamore observations retain [Benjamin Zeigler's pinned MIT source](https://github.com/sololegends/runelite-varlamore-house-thieving/tree/ed8c58e1e9dbc73508187c1d88000c61115aee6e) plus separately attributed Wiki timing facts.
- `CombatSpellCatalog` holds 42 numeric autocast spell facts, with the exact [Wiki DPS source commit](https://github.com/weirdgloop/osrs-dps-calc/blob/89c3e25b344aea90d0189746e4b5f73dde0f0383/cdn/json/spells.json) in `combat-spells-attribution.txt`. The upstream GPL-3.0 license document is preserved as `mob-knowledge-upstream-GPL-3.0.txt` for provenance. No upstream calculator implementation is included. Supported normal base-max-hit arithmetic and its reference scope are described in `max-hit-reference-attribution.txt`.
- Action timing sources and revisions remain in `action-progress-attribution.txt`. Generic Wiki attribution does not replace individual per-entry source links or third-party licenses.
- Harvest-run preparation uses the native item identities and the selected Wiki facts/revisions listed in `harvest-run-reference.txt`: ready saplings, optional protection payments, birdhouse logs/prebuilt alternatives, clockwork reuse and accepted seeds. Stored or unobserved supplies are not inferred from the player's equipment.
- Slayer reads current assignments, counts, points and the appropriate streak directly from public native variables and DB rows. Fifteen recognized area names use selected bounds from [117HD's area facts at 5be607e0](https://github.com/117HD/RLHD/blob/5be607e0d99737f69b3bf4282b2655fe959f1a63/src/main/resources/rs117/hd/scene/areas.json), retaining the complete notice in `slayer-area-RLHD-BSD-2-Clause.txt`. Restricted or instanced locations without a recognized match do not activate the floating card. The sidebar remains available. Point balances and observed completion gains are separate; anticipated completion rewards are not inferred.

The broader prototype's guide, quest, encounter, Slayer planning, DPS/monster/equipment, minigame, world-hopper and reward datasets/assets are absent. No executable reference code is downloaded by the running plugin.

When changing data, retain source revisions, license terms and preparation notes. Inspect the source and data changes before regenerating `docs/data-manifest.json` with `python tools/validate_bundle.py --write`; validation consumes the checked-in resources directly. Unknown native observations must remain unknown rather than becoming invented completion or timing facts.

Varlamore timing was rechecked against the Wiki raw pages on 2026-10-18. Distractions occur simultaneously at the three locations in randomized 84–99 second start-to-start cycles and last up to24 seconds. Native NPC transitions or the native game message anchor a witnessed start. Mid-cycle first sightings display lower/upper bounds; no exact start is inferred. House entrances derive from the pinned native house bounds and are checked against the supplied Shortest Path collision map in companion integration tests.
